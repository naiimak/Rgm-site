# JellyFit brand assets

These files are kept in the repo for reference and are **not** published on the website. Netlify only publishes `public/`.

## Logo: "Jelly Drop"

The JellyFit wordmark (Nunito Black, converted to outlines) with the dot of the **i** replaced by a jelly drop.

| File | Use |
|---|---|
| `logo/jellyfit-logo.svg` / `.png` | Main logo: raspberry lettering, pink drop. Use on cream, white or light backgrounds |
| `logo/jellyfit-logo-white.svg` / `.png` | On raspberry, dark or photo backgrounds |
| `logo/jellyfit-logo-black.svg` | One-color printing (stamps, receipts, single-color stickers) |
| `icon/jellyfit-icon.svg` / `jellyfit-icon-512.png` | App icon / favicon: white **j** with pink drop on raspberry |
| `icon/jellyfit-icon-cream.svg` | Icon on a cream background |
| `social/profile-raspberry.png` | WhatsApp / Instagram profile picture (1080×1080, safe for a round crop) |
| `social/profile-cream.png` | Alternative light profile picture |

SVG files stay sharp at any size and need no fonts installed. Use the PNGs where SVG isn't accepted.

| Mango (second flavor) | `#F29F1D` |

## Rules of thumb

- Leave clear space around the logo at least the height of the jelly drop.
- Don't stretch, rotate, outline or add shadows to the logo.
- Don't recolor the lettering in mango. Mango is a flavor color, not the brand color.
- The smallest size for the full wordmark is about 80 px wide on screen. Below that, use the **j** icon.

See `BRAND-BRIEF.md` for the full brief: product, tone, typography and claim rules.
